# Superstore Sales Statistical Analysis
## Overview
This project analyses the factors associated with **Profit** using the Superstore dataset.

The analysis focuses on:
- Discount
- Sales
- Quantity
- Profit

Multiple Linear Regression is used to examine the relationship between these variables.

## Dataset
The dataset contains **9,994 observations** and 22 variables.

## Methods
The project includes:
- Exploratory Data Analysis (EDA)
- Multiple Linear Regression
- Regression diagnostics
- Robust standard errors (HC3)
- Variance Inflation Factor (VIF) analysis

## Diagnostics
The following diagnostic plots are included:
- Boxplot of Profit
- Residuals vs Fitted
- Scale-Location
- Normal Q-Q Plot
- Residuals vs Leverage

## Main Findings
The regression model shows that **Discount and Sales are significantly associated with Profit**, while Quantity is not statistically significant after accounting for the other variables.

The diagnostic analysis indicates heteroscedasticity and departures from normality, so HC3 robust standard errors were used.
